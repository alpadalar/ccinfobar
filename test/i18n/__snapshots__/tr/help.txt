ccinfobar X.Y.Z
Claude Code için özelleştirilebilir, GSD uyumlu durum satırı

Kullanım
  ccinfobar                       Durum satırını görüntüler (Claude Code JSON'unu stdin'den okur)
  ccinfobar edit                  Sürükle-bırak editörü tarayıcınızda açar
  ccinfobar editor                edit ile aynı
  ccinfobar edit --detach         Editörü arka planda başlatır, URL'sini yazar ve çıkar
  ccinfobar edit --open <code>    Editörü bir paylaşım kodu yüklü olarak açar (Kaydet'e basana kadar hiçbir şey kaydedilmez)
  ccinfobar tui                   Terminal editörünü açar
  ccinfobar install               Claude Code'un statusLine ayarını ccinfobar'a yönlendirir
  ccinfobar install --project     Bu projenin kendi statusLine ayarını da devralır (örn. GSD'ninkini)
  ccinfobar install --no-global   npx ile: ccinfobar komutunu global olarak kurmaz
  ccinfobar install --dry-run     Kurulumun neyi değiştireceğini gösterir, hiçbir şey yazmaz
  ccinfobar install --hooks       İsteğe bağlı Claude Code hook'larını da ekler (kesin canlı durum için)
  ccinfobar install --progress    Bağlam doluluğunu terminal sekmesinin ilerleme çubuğunda da gösterir
  ccinfobar uninstall             ccinfobar'ı kaldırır ve önceki durum satırınızı geri getirir
                                  `npm rm -g ccinfobar` öncesinde çalıştırın: hook'lar ccinfobar komutunu çağırır
  ccinfobar uninstall --hooks     Yalnızca ccinfobar'ın hook'larını kaldırır
  ccinfobar uninstall --progress  Yalnızca terminal ilerleme işleyicilerini kaldırır
  ccinfobar subagent-line         Claude Code alt ajan paneli satırları (install --subagents ile kurulur)
  ccinfobar import <tool>         Başka bir durum satırının düzenini içe aktarır (bkz. ccinfobar import --help)
  ccinfobar import <tool> --dry-run
                                  Eşleme raporunu ve önizlemeyi gösterir, hiçbir şey yazmaz
  ccinfobar themes                Tüm temaları önizler
  ccinfobar themes --list         Yalnızca tema id'lerini ve adlarını listeler
  ccinfobar theme <id>            Temayı değiştirir
  ccinfobar theme new <id>        Kendi temanızı oluşturur (--from <theme>)
  ccinfobar theme rotate <id...> [--every hour|day|week|<min>] [--shuffle]
                                  Temaları saate, güne, haftaya ya da dakikaya göre sırayla veya karışık döndürür
  ccinfobar theme rotate --weekdays mon=nord,...
                                  Bir haftanın gününe tema sabitler (off listeyi temizler)
  ccinfobar theme rotate off      Tema döngüsünü kapatır
  ccinfobar init [preset]         Hazır ayar yapılandırması yazar (default, cockpit, dashboard, minimal, gsd, powerline, full, cost, limits, git, workspace, compact, two-line, agents, charts, session)
  ccinfobar catalog list|show|history
                                  Yerleşik ve kayıtlı hazır ayarlara, temalara ve paketlere göz atar (--remote: marketplace)
  ccinfobar catalog install <publisher>/<slug>
                                  Bir marketplace girdisini komutlarını ve URL'lerini gösterdikten sonra kataloğunuza yükler
  ccinfobar catalog apply <ref|code>|save <name>
                                  Bir katalog girdisini veya paylaşım kodunu uygular ya da düzeninizi girdi olarak kaydeder; tüm alt komutlar için ccinfobar catalog çalıştırın
  ccinfobar catalog publish       Paylaşılan girdilerinizi gösterir, sonra marketplace adresine gönderir
  ccinfobar catalog login|logout  GitHub ile marketplace'e giriş yapar veya çıkış yapar
  ccinfobar share                 Düzeniniz ve temanız için bir paylaşım kodu yazdırır (kişisel ayarlar dahil edilmez)
  ccinfobar preview               Durum satırını örnek verilerle yazdırır
  ccinfobar preview --scenario <name>
                                  Adı verilen bir durumu önizler (liste için --scenario)
  ccinfobar preview --glyph-mode <mode>
                                  Bir glif moduyla önizler, örn. GitHub issue'ları için paste-safe
  ccinfobar update                Son sürüme günceller (yalnızca bakmak için --check)
  ccinfobar update --check        yalnızca yeni sürüm var mı diye bakar, hiçbir şeyi değiştirmez
  ccinfobar usage                 Plan kullanımınızı şimdi Claude'dan çeker
  ccinfobar widgets               Tüm bileşenleri listeler
  ccinfobar doctor                Kurulumu denetler
  ccinfobar explain [widget-id]   Her bileşenin değerini, kaynağını ve neden boş olduğunu gösterir
  ccinfobar explain --scenario <name>
                                  Adı verilen bir durum için bileşenleri açıklar
                                  (tek başına --scenario senaryoları listeler)
  ccinfobar bench                 Görüntüleme süresini ölçer: soğuk, sıcak, medyan ve p95
  ccinfobar report                Son 7 gün için proje başına token, tahmini maliyet ve aktif süreyi gösterir
  ccinfobar report --period day|week|month
                                  Güne, haftaya ya da aya göre gruplar (son 7 gün, 4 hafta ya da 3 ay)
  ccinfobar report --csv|--json   Raporu CSV ya da JSON olarak yazdırır
  ccinfobar report --rebuild      Tüm transkriptleri yeniden okur ve maliyet kaydı özetini onarır
  ccinfobar config get <path>     Bir yapılandırma değerini yazdırır (örn. theme, lines.0.2.type)
  ccinfobar config set <path> <value>
                                  Bir değer atar (JSON, değilse dize); geçersiz değerler reddedilir
  ccinfobar config unset <path>   Bir değeri kaldırır (varsayılan geri gelir)
  ccinfobar repos --background <dir>
                                  workspace-repos bileşeni kullanır: bir klasörü arka planda tarar
  ccinfobar hook <Event>          Claude Code hook'ları kullanır (çıktı vermez)

Seçenekler
  --config <file>                 Belirli bir yapılandırma dosyası kullanır
  --payload <file>                Bir JSON payload dosyasıyla görüntüler
  --width <n>                     Algılanan terminal genişliğini geçersiz kılar
  --scenario <name>               preview/explain/bench: adı verilen bir senaryoyu kullanır (tek başına listeler;
                                  bench yalnızca payload ve env değerlerini kullanır)
  --runs <n>                      bench: tekrar sayısı (varsayılan 20, en fazla 1000)
  --json                          explain, bench, report: tek bir JSON nesnesi yazdırır
  --csv                           report: CSV yazdırır
  --show-values                   explain: terminalde env, komut ve araç etkinliği değerlerini ve metin seçeneklerini de gösterir
  --refresh <seconds>             install: statusLine.refreshInterval değerini de ayarlar
  --project                       install/uninstall: buradaki .claude/settings.local.json dosyasını kullanır
  --project <filter>              report: yalnızca yolunda bu metin geçen projeler (. = bu proje)
  --since <date> / --until <date>
                                  report: ilk ve son gün, YYYY-MM-DD ya da 7d, 4w, 3m geriye
  --all                           report: geçmişin tamamı
  --format table|csv|json         report: çıktı biçimi (varsayılan table)
  --import / --no-import          install: önceki durum satırının düzenini sormadan içe aktarır (yapılandırma varken terminal yokken gerekir)
  --file <path>                   import: bu ayar dosyasını okur
  --allow-commands                import, install: içe aktarılan komutları, URL'leri ve ortam değişkeni bileşenlerini sormadan korur
  --include-commands              share: komut, HTTP, bağlantı ve ortam değişkeni bileşenlerini kodda tutar
  --command <cmd>                 install: yazılacak komut (varsayılan: auto); import: okunacak durum satırı komutu
  --hooks[=permission]            install: hook'ları ekler (=permission, PermissionRequest de ekler);
                                  uninstall: yalnızca ccinfobar'ın hook'larını kaldırır
  --progress                      install: terminal ilerleme işleyicilerini ekler (Claude Code 2.1.141+);
                                  uninstall: yalnızca bunları kaldırır
  -y, --yes                       install: başka bir aracın statusLine ayarını sormadan değiştirir
  --dry-run                       install, import: planı gösterir, hiçbir şey yazmaz
  --port <n>                      edit: dinlenecek port
  --detach                        edit: arka planda çalışır; 30 dakika boşta kalınca durur
  --no-open                       edit: tarayıcı açmaz
  --no-detect                     edit: terminale renklerini sormaz
  --list                          themes: id'leri ve adları yazdırır, önizleme yok
  -v, --version                   Sürümü yazdırır
  -h, --help                      Bu yardımı gösterir
