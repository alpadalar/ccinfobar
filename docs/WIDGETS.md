# Widgets

> Generated by `npm run docs`. Do not edit by hand.

ccinfobar ships 117 widgets. A widget without data shows its label and `—`; set `hideEmpty: true` on it to hide it instead (handy for a GSD line outside GSD projects). `git-is-fork`, `workspace-repos`, `service-status` hide themselves when empty; set `hideEmpty: false` on one to show `—` instead.

Common fields for every widget in `config.json`: `color`, `background`, `bold`, `dim`, `italic`, `label`, `raw` (value only, no label), `merge` (no separator after it), `hideEmpty` (hide instead of showing `—` when there is no data), `showWhen` and `hideWhen` (rules for when it shows), `priority` (0-100, kept longer with `overflow: priority`) and `options`.
