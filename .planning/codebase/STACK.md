# Technology Stack

**Analysis Date:** 2026-10-14

## Languages

**Primary:**
- TypeScript (devDependency `typescript` ^7.0.2, target ES2022) - all source in `src/`, tests in `test/`, scripts in `scripts/*.ts`
  - `strict`, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`, `isolatedModules`; `noEmit` (see `tsconfig.json`)

**Secondary:**
- JavaScript (ESM `.mjs`) - build script `scripts/build.mjs`
- HTML/CSS - browser editor UI in `src/editor/web/index.html`, `src/editor/web/style.css`, inlined into the bundle at build time

## Runtime

**Environment:**
- Node.js >=20 (`engines` in `package.json`); esbuild target `node20`; CI matrix Node 20, 22, 24
- ESM only (`"type": "module"`); relative imports use `.js` suffix
- Must run on Linux, macOS, Windows

**Package Manager:**
- npm
- Lockfile: present (`package-lock.json`)

## Frameworks

**Core:**
- None. Zero runtime dependencies; uses only Node built-ins (`node:fs`, `node:path`, `node:os`, `node:crypto`, `node:child_process`, `node:http`, `node:net`, `node:module`, global `fetch`).
- Browser editor is vanilla TypeScript (`src/editor/web/app.ts`, `src/editor/web/api.ts`), no UI framework.

**Testing:**
- Vitest ^5.0.4 - config `vitest.config.ts` (`test/**/*.test.ts`, node environment)

**Build/Dev:**
- esbuild ^0.28.2 - `scripts/build.mjs` bundles `src/bin.ts` to `dist/ccinfobar.js` (ESM, code splitting into `dist/chunks/`), bundles the web editor as an IIFE and inlines it as `__EDITOR_HTML__`; `__VERSION__` injected via `define`
- Biome ^2.5.15 - lint + format (`biome.json`)
- `@types/node` ^22.20.5

## Key Dependencies

All are devDependencies (see `package.json`); nothing ships at runtime.

**Critical:**
- `esbuild` - produces the single distributable
- `typescript` - typecheck only (`npm run typecheck`)
- `vitest` - test runner

**Infrastructure:**
- `@biomejs/biome` - lint/format; style: 2 spaces, single quotes, semicolons, trailing commas, line width 110

## Configuration

**Environment:**
- User config JSON at `$XDG_CONFIG_HOME/ccinfobar/config.json` (Linux/macOS), `%APPDATA%\ccinfobar` (Windows); resolved in `src/core/paths.ts`
- Cache dir: `$XDG_CACHE_HOME/ccinfobar` / `~/Library/Caches/ccinfobar` / `%LOCALAPPDATA%\ccinfobar\cache`
- Env vars read: `CCINFOBAR_CONFIG`, `CCINFOBAR_CONFIG_DIR`, `CCINFOBAR_CACHE_DIR`, `CCINFOBAR_GIT_TIMEOUT`, `CCINFOBAR_NO_DETECT`, `CCINFOBAR_NO_UPDATE`, `CCINFOBAR_NO_USAGE_API`, `CLAUDE_CONFIG_DIR`, `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, `CLAUDE_SECURESTORAGE_CONFIG_DIR`, `CLAUDE_POWERLINE_CONFIG`, `GSD_WORKSTREAM`, `NO_COLOR`, `FORCE_COLOR`, `COLORTERM`, `COLUMNS`, `TERM_PROGRAM`, `WT_SESSION`, `CI`, `XDG_*`, `APPDATA`, `LOCALAPPDATA`
- JSON schemas: `schema/config.schema.json`, `schema/theme.schema.json` (generated by `npm run docs`)
- `.env` files: not detected

**Build:**
- `scripts/build.mjs` (`--watch`, `--docs`, `--demo`), `scripts/gen-docs.ts` (generates `docs/WIDGETS.md` and schemas), `scripts/demo-gif.ts`
- `tsconfig.json`, `biome.json`, `vitest.config.ts`, `.editorconfig`

## Platform Requirements

**Development:**
- Node 20+, npm; commands: `npm run check` (typecheck + lint + test), `npm run build`, `npm run dev`, `npm run docs`

**Production:**
- Distributed as npm package `ccinfobar` (bin `dist/ccinfobar.js`; published files `dist/`, `schema/`) and as a GitHub release tarball `ccinfobar.tgz`
- Runs as a Claude Code `statusLine` command reading JSON payload on stdin
