# Codebase Structure

**Analysis Date:** 2026-10-14

## Directory Layout

```
claude-code-info-bar/
├── src/
│   ├── bin.ts            # Node entry (shebang)
│   ├── cli.ts            # Arg parsing, command dispatch, render path
│   ├── commands/         # install, update, doctor
│   ├── core/             # types, config, context, renderer, panel, ansi, themes, edit, presets, sample, preview, paths, load
│   ├── data/             # agents, cache, git, gsd, history, terminal, transcript, usage
│   ├── widgets/          # one file per category + index.ts registry + shared.ts
│   ├── importers/        # ccstatusline, claude-powerline, index
│   ├── editor/           # server.ts (HTTP), terminal-colors.ts, web/ (browser app)
│   └── tui/              # state, view, keys, hits, fields, catalog, themeio, index
├── test/                 # vitest suites mirroring src areas + fixtures
├── scripts/              # build.mjs, gen-docs.ts, demo-gif.ts
├── schema/               # generated config/theme JSON schemas
├── docs/                 # CONFIGURATION, DEVELOPMENT, GSD, THEMES, WIDGETS(generated)
├── .github/              # CI, release workflows, templates
├── dist/                 # build output (ignored)
└── package.json, tsconfig.json, biome.json, vitest.config.ts
```

## Directory Purposes

**`src/core/`:**
- Purpose: platform-agnostic logic. Key: `renderer.ts`, `panel.ts`, `config.ts`, `types.ts`, `edit.ts` (browser-safe, pure).

**`src/widgets/`:**
- Purpose: widget definitions per category: `agents, charts, context, cost, custom, git, gsd, layout, limits, session, system, tokens, workspace`. Registered in `src/widgets/index.ts`.

**`src/data/`:**
- Purpose: readers with caching. `transcript.ts` is incremental; `gsd.ts` parses `.planning/`.

**`src/editor/web/`:**
- Purpose: browser app bundled by esbuild into `index.html` (inlined). Files: `app.ts` (entry), `store.ts`, `api.ts`, `inspector.ts`, `panel-inspector.ts`, `dnd.ts`, `themes.ts`, `theme-builder.ts`, `style.css`.

**`src/tui/`:**
- Purpose: terminal editor; `state.ts` reducer, `view.ts` rendering, `keys.ts` input parsing, `index.ts` IO loop.

**`test/`:**
- Subdirs: `core, themes, widgets, data, gsd, editor, tui, commands, importers, integration, fixtures`. Helpers: `test/helpers.ts` (`ctxWith`, `renderWidget`).

## Key File Locations

**Entry Points:**
- `src/bin.ts`: process entry; `src/cli.ts`: `main()`.

**Configuration:**
- `package.json`, `tsconfig.json`, `biome.json`, `vitest.config.ts`, `.editorconfig`.
- Runtime paths: `src/core/paths.ts`.

**Core Logic:**
- `src/core/renderer.ts`, `src/core/panel.ts`, `src/core/context.ts`, `src/widgets/index.ts`.

**Testing:**
- `test/**/*.test.ts`; fixtures `test/fixtures/payload.json`, `test/fixtures/transcript.jsonl`, `test/fixtures/gsd/*`.

## Naming Conventions

**Files:**
- lowercase kebab-case `.ts` (`install-dialog.ts`, `panel-inspector.ts`); tests `<name>.test.ts` under mirrored `test/<area>/`.

**Directories:**
- lowercase, single word.

**Widget types:** kebab-case strings (`git-branch`, `context-bar`, `gsd-phase`, `session-cost`).

## Where to Add New Code

**New widget:**
- Add `WidgetDef` to the matching category file in `src/widgets/`; new category requires entry in `CATEGORIES` and `WidgetCategory` (`src/core/types.ts`) plus spread in `ALL_WIDGETS`.
- Tests: `test/widgets/`; then `npm run docs` and commit `docs/WIDGETS.md`, `schema/*.json`.

**New data source:**
- Reader in `src/data/`, expose via `DataSources` in `src/core/types.ts` and lazy thunk in `src/core/context.ts`.

**New CLI command:**
- Add `case` in `main()` of `src/cli.ts` and HELP text; larger logic in `src/commands/`.

**New config edit operation:**
- `src/core/edit.ts` (pure); use from `src/editor/web/` and `src/tui/state.ts`; test in `test/core/edit.test.ts`.

**New editor API route:**
- `src/editor/server.ts` switch on `METHOD /api/...`; client call in `src/editor/web/api.ts`; test in `test/editor/server.test.ts`.

**New theme/preset:**
- `src/core/themes.ts` / `src/core/presets.ts`; tests in `test/themes/`, `test/core/presets.test.ts`.

**Utilities:**
- Widget helpers: `src/widgets/shared.ts`; ANSI helpers: `src/core/ansi.ts`.

## Special Directories

**`dist/`:** build output, generated, not committed.
**`schema/`:** generated by `npm run docs`, committed.
**`docs/WIDGETS.md`:** generated, committed.
**`test/fixtures/gsd/`:** sample `.planning` projects for parser tests, committed.
**`.planning/`:** GSD planning artifacts (this map lives in `.planning/codebase/`).
